## Important for agents

Geniemode does NOT operate a public API program. There is no developer portal, no documentation
site, no self-service signup, no SDK, no CLI, no MCP server and no published pricing. A
machine-readable contract IS publicly readable (see below), but every operation it describes
returns HTTP 401 without an authenticated portal session, and portal accounts are provisioned by
Geniemode to buyers, suppliers, sales agents and staff. An agent cannot call this API.

management.
